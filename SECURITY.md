# Безопасность

## Поддерживаемые версии

Исправления выходят только для последней версии со страницы [Releases](https://github.com/uproxe/SigurToPerco/releases).

## Как сообщить об уязвимости

Не создавайте публичный issue — напишите владельцу репозитория лично.
Если репозиторий публичный, можно воспользоваться **Security → Report a vulnerability**.

## Персональные данные

Программа работает полностью локально: ничего не отправляет в сеть и не сохраняет, кроме файла
для PERCo, который вы сами выбираете. Выгрузки сотрудников содержат персональные данные —
не публикуйте их в issue, pull request или в репозитории.
