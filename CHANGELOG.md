# История изменений

## 0.3.0 — первая публичная версия

**Пересчёт номеров**
- Номер из Sigur (W58, HEX) → номер PERCo «серия/номер» на лету, и обратно.
- Вставка `Ctrl+V` сразу кладёт результат в буфер обмена; работает в любой раскладке.
- Список номеров с копированием в Excel двумя колонками, история пересчётов.

**Выгрузка сотрудников**
- Выгрузка Sigur (`.xls`, `.xlsx`, «xls» в виде HTML-таблицы) → таблица импорта PERCo-Web.
- Предпросмотр, сводка и список предупреждений; несколько пропусков у одного человека.
- Перетаскивание файла в окно или на значок программы.

**Интерфейс**
- Скруглённые кнопки, карточки и поля со сглаживанием, тонкие скрывающиеся полосы прокрутки,
  переключатели, плоская таблица — средствами tkinter, без сторонних библиотек.

**Сборка**
- GitHub Actions: Windows (в т.ч. Windows 7), Linux (`.deb`, `.tar.gz`), macOS (Apple Silicon, Intel).
- Тесты логики и проверка окна со скриншотами при каждом изменении.
