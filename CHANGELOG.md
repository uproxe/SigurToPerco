# История изменений

## 3.0.0

- Одна программа вместо нескольких: пересчёт номера пропуска и конвертация выгрузки в одном окне.
- Пересчёт на лету, обратный пересчёт PERCo → Sigur, список номеров с копированием в Excel, история.
- `Ctrl+C / Ctrl+V` в любой раскладке, меню по правой кнопке, перетаскивание файлов в окно.
- Предпросмотр таблицы для PERCo, сводка и список предупреждений.
- Чтение «xls», которые на самом деле HTML-таблица.
- Сборки под Windows (в т.ч. Windows 7), Linux (.deb, .tar.gz) и macOS (Apple Silicon, Intel) через GitHub Actions.
- Новый значок.
