## [0.3.0] - 2026-11-18

Первая публичная версия.

### Добавлено

- Пересчёт номера пропуска из Sigur (W58, HEX) в номер PERCo «серия/номер» на лету и обратно.
- Вставка `Ctrl+V` сразу кладёт результат в буфер обмена; `Ctrl+C / Ctrl+V` работают в любой раскладке.
- Список номеров с копированием в Excel двумя колонками, история пересчётов.
- Конвертация выгрузки сотрудников Sigur (`.xls`, `.xlsx`, «xls» в виде HTML-таблицы) в таблицу импорта PERCo-Web:
  предпросмотр, сводка, предупреждения, несколько пропусков у одного человека.
- Перетаскивание файла в окно или на значок программы, меню по правой кнопке мыши.
- Современный интерфейс средствами tkinter: скруглённые кнопки, карточки и поля, тонкие полосы прокрутки,
  переключатели, плоская таблица; компактный режим для невысоких экранов.
- Сборки через GitHub Actions: Windows (в том числе Windows 7), Linux (`.deb`, `.tar.gz`),
  macOS (Apple Silicon и Intel); тесты логики и проверка окна со скриншотами.
